Dial-Up Telephone

The drawing game that travels by modem sound.

The chirps are how the game sends drawings and guesses between phones, so they always play. This switch only turns off the decorative sounds. Turn it off if chirps are often missed.

Diagnostics
Microphone off

Remember telephone? Now every message hops between phones as the screech of a 1980s dial-up modem, and the bad old phone line adds static on the way. One player draws a secret word, the next guesses the drawing, the next draws the guess… then everyone watches how badly it mutated, scores points, and votes for the worst connection. No internet. Only sound.

  1. 3–8 players, each with a phone or laptop. Sit in a circle in seat order.
  2. Allow the microphone and turn the volume up. On iPhone, turn off silent mode.
  3. Keep devices within about 1 m of each other. Be quiet while a chirp plays.
  4. Missed a chirp? The sender presses Resend. Nothing breaks.

Only one device? Open this page in several browser windows. Each window is one player.
